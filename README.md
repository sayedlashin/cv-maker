# مُولد السيرة الذاتية الذكي (Smart CV Generator)

تطبيق ويب احترافي باللغة العربية لبناء سير ذاتية متوافقة مع أنظمة تتبع المتقدمين (ATS).

## المميزات:
- **تحميل بصيغة Word**: تصدير السيرة الذاتية بتنسيق نظيف واحترافي متوافق مع ATS.
- **استخراج البيانات بالذكاء الاصطناعي**: يمكنك رفع سيرة ذاتية قديمة (PDF/Docx) وسيقوم التطبيق باستخدام Gemini لاستخراج البيانات منها تلقائياً.
- **معاينة حية**: شاهد التغييرات على سيرتك الذاتية في نفس الوقت.
- **دعم كامل للغة العربية**: تنسيق RTL (من اليمين لليسار) مدروس بعناية.
- **متوافق مع الهواتف**: يعمل بسلاسة على جميع الأجهزة.

## التقنيات المستخدمة:
- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion.
- **Backend**: Node.js, Express, Gemini API.
- **Document Generation**: docx library.
- **AI Extraction**: Google Gemini 3 Flash.

## كيف يعمل؟
1. قم بتعبئة البيانات يدوياً أو ارفع ملف قديم ليقوم الذكاء الاصطناعي بالمهمة عنك.
2. عدل البيانات حسب حاجتك.
3. اضغط على "تحميل الملف" للحصول على نسخة جاهزة للتقديم.
